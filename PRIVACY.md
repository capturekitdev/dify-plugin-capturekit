# Privacy policy

This plugin is published by CaptureKit (https://www.capturekit.dev).

## What the plugin sends

When a tool runs, the plugin sends the URL of the page and the capture options, or your question about the page to the CaptureKit API at `https://api.capturekit.dev`, with your API key in the `x-api-key` header. When you save the API key in Dify, the plugin checks it with one request that costs no credits.

The plugin calls no other host.

## What the plugin stores

The plugin stores nothing. It keeps no logs, files or caches. Dify stores the API key you enter, as it does for every plugin credential.

## What CaptureKit does with the data

CaptureKit processes requests to return results and to count credits on your account. See the CaptureKit privacy policy: https://www.capturekit.dev/privacy
